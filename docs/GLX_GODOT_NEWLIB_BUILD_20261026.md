配置准备只检查了工具链 JSON 的两个变化项和 SDK 文件，遗漏了与旧 `hostRuntime` 的前置比较。构建后的独立保全核对发现此问题。下次必须在启动前核验旧驱动 Node 的路径、字节、版本和整体构建身份；本轮没有自动修正后重跑。
