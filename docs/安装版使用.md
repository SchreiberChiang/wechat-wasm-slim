# Godot 微信 GLX 插件安装版

和其他 Godot 插件一样安装。需要本机装有 Godot 4.7.2 和微信开发者工具。Node.js 已经随插件附带，不用另外安装。

**安装**

1. 把发布包里的 `addons` 文件夹复制到游戏工程根目录（和 `project.godot` 同一层）。复制后游戏里有 `addons/wxslim_readonly/`。
2. 用 Godot 打开游戏，在「项目 → 项目设置 → 插件」里勾选启用「微信导出·本地开发任务面板」。
3. 插件会自动完成准备：核对工具包、记下当前的 Godot，并在游戏外面建立任务目录。几秒后右侧出现「微信导出」面板。

**升级**：关掉 Godot，把游戏里的 `addons/wxslim_readonly` 整个删掉，再复制新版本的进去。重新打开 Godot 后，插件会自动重新准备。

插件文件夹约 313 MB，其中 `kit/` 是工具包（三套引擎、微信转换器、导出脚本和 Node.js 24.18.0，Node.js 的许可见 `kit/tools/node/LICENSE`）。`kit/` 里有一个 `.gdignore` 空文件，Godot 不会扫描、导入或导出它，所以不会让游戏包变大。游戏用 Git 管理时，可以把 `addons/wxslim_readonly/kit/` 加进 `.gitignore`。

想让 AI 帮忙安装，把发布包和其中的《给AI的安装说明.md》一起交给它。

用 Godot 打开游戏，右侧出现「微信导出」停靠栏：

- 选模板（完整、保守或 2D）、填 AppID 和输出目录并保存，点「导出并转换」，完成后点「在开发者工具中打开」。运行中可点「取消」，不回滚；「高级 → 最近运行」可以重新打开以前的输出，或把取消、失败留下的目录移到回收站。
- 保守版去掉 ENet 联机、FBX/GLTF 导入、VR/XR、UPnP 和凸分解碰撞；2D 去掉全部 3D 功能。选这两种要勾选确认游戏没用到这些功能，转换时会自动核对安装版内的引擎指纹单。
- 「运行效果」里还可以选语言（简体中文或英文）、大 PCK（转换预算 144 MiB）和临时登录 code（只在完整模板可用，未实测）。选 GLX 且语言为简体中文时会另生成电脑预览包：开发者工具走 WebGL2，真机走 GLX。
- 「资源分包」选「按场景分包」后添加要延后下载的场景。第一次要点「装分包加载脚本…」，确认后插件往游戏里新建 4 个脚本并加自动加载 WxResource。导出时插件自动把每个场景独占的资源拆成分包，被首包或多个场景共用的资源留在首包。游戏代码要在进入这些场景前调用 `WxResource.load_pack("包名")`；用字符串拼路径动态加载的资源分析不到，需要自己确认。
- 检查没通过时，提示框说明原因，点「确定」后自动展开对应的设置。

自建引擎（自己裁剪模块重新编译）和按请求文件打开任意任务只在命令行提供，见源码的离线开发说明。

本机记录放在游戏自己的 `.godot/wxslim/` 中（不进版本库），任务状态默认放在本机 LOCALAPPDATA/Godot/WxSlim/projects 的项目专属目录。换了 Godot、移动了工程或换了插件版本时，插件启用时会自动重新准备；也可以手动运行 `addons/wxslim_readonly/kit/tools/node/node.exe addons/wxslim_readonly/kit/install.mjs Godot编辑器.exe`（可加 `--state-root 目录` 把任务状态放到游戏外的指定位置）。准备时会核对 `kit/RELEASE.json` 里每个文件的字节，并在 project.godot 中启用插件：插件注册的导出过滤负责把面板脚本排除出游戏包。命令行导出时如果插件装了却没启用，会直接提示，不会继续导出。微信开发者工具安装目录须位于启动 Godot 时的 PATH。

| 面板模板 | 引擎文件 |
|---|---|
| 完整 | engines/full/ |
| 保守 | engines/conservative/ |
| 2D | engines/pure-2d/ |

面板自动选用对应目录里的 godot.prepared.js、godot.wasm 和 tools/wx-transformer-v1.0.35-win.exe，不用手动挑文件。保守和 2D 由各自引擎目录里的 fingerprint.json 核对，并要求一份与本次 PCK 绑定的功能声明（面板里的确认勾选）。选择 GLX 时实际设备能力不足会显式报错，选 WebGL 可做本地桌面对照。

每次导出并转换都在输出目录下新建一个运行目录，不覆盖旧输出。开发者工具打开的是电脑预览包或转换结果里的 project.config.json，AppID 用面板里填的或从文件读到的。游戏 PCK、AppID、测试账号、运行日志和签名材料单独管理。

日常安装与使用用本目录。Claude 修改界面、修复功能或合并补丁都使用单独的 source 项目，回归通过后由维护脚本再生成安装版。
