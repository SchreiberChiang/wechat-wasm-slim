## 已落实的验收行为

20 项分别是：图片方向、中文放大、半透明叠加、裁剪边界、面板拉宽、面板拉高、边砖平铺与完整、竖边/中心平铺、隐藏/显示中心、更换透明边框、方块贴图/转动、左右灯光、前方透明红片、后方蓝片遮挡、只切换左窗、只转动右窗、右窗放大/恢复、持续观察两分钟、回桌面后恢复、清空/重新创建。

每项显示中文动作、看得见的预期和异常例子；画面、操作、停顿独立填写，默认未测试，保留看不清/没留意。目录可直接选择任一项。结果只在当前运行保留，不能承诺退出后恢复；通过完整 vConsole 导出留证，不启用云上报。

准备提示先进入真实 `frame_post_draw` 回调，再创建内容；资源创建结束、后续绘图回调及原始时长均记录。没有固定等待冒充准备完成；程序不会自动勾选画面通过。**引擎回调并非屏幕呈现证据，提示不是性能优化。** 未引入材质常驻，原有卡顿问题 GLX-20 未关闭。

新场景 3D 直接使用 BoxMesh，不调用此前触发 GLX-19 的 `surface_get_arrays()`。11–14 项测试主视口直接 3D；15–20 项使用独立 SubViewport 世界。图案编号和箭头作可辨别参照；示意采用不同绘法，但最终仍经同一显示链路，不是独立 GPU 正确性证明。

电脑实现中修正了场景自身的中文字体主题跨 CanvasLayer 继承、跨 SubViewport 字体、BoxMesh 贴图图集映射和目录安全区布局；都没有改引擎/GLX 接线。
