## 使用插件的人需要知道

- 用插件导出的小游戏，会带上微信的 GLX 组件和适配代码。发布小游戏时须遵守微信小游戏平台的规则，这和直接用微信官方工具导出一样。
- 如果你不能接受某个组件的条件，就不要使用本插件。也可以按上面的官方地址自己下载对应的微信工具，并核对 SHA-256（见 `packaging/vendor-lock.json`）。
- 如果你是权利人，认为某个文件不应该出现在这里，请在 GitHub 提 issue，作者会尽快处理。
